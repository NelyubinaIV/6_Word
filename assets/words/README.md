# Файлы слов

Для каждого слова используйте его реальный `wordId` из API. Это исключает проблемы с пробелами, ударениями и кириллицей в именах файлов.

## Изображения

Папка: `assets/words/images/`

Имя: `word-<wordId>.png`

Пример для `wordId = 17`:

`assets/words/images/word-17.png`

Рекомендуемый размер: 1200×900 px или соотношение 4:3. Формат: PNG. Желательно без текста внутри изображения.

## Аудио

Папка: `assets/words/audio/`

Имя: `word-<wordId>.mp3`

Пример:

`assets/words/audio/word-17.mp3`

Формат: MP3, один файл — одно чётко произнесённое слово, без музыки и длинной паузы.

## Пути в данных

Соответствующие значения для API/YDB:

- `image_path`: `./assets/words/images/word-17.png`
- `audio_path`: `./assets/words/audio/word-17.mp3`

Если у слова нет файла, оставляйте поле пути пустым. Интерфейс покажет штатную космическую иллюстрацию и скроет кнопку аудио.
